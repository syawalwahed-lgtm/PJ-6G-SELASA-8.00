# PJ Tahun 6 — Pengembaraan Imbangan Cantik

Pakej ini disediakan untuk GitHub Pages. Fail utama telah dinamakan **`index.html`** supaya halaman utama boleh dibuka apabila pelawat melayari URL repositori Pages.

## Cara muat naik ke GitHub Pages

1. Muat turun dan ekstrak ZIP ini.
2. Buka repositori GitHub anda: `https://github.com/syawalwahed-lgtm/PJ-6G-SELASA-8.00/`.
3. Muat naik **semua kandungan di dalam folder ini** ke akar repositori pada branch `main` (jangan muat naik folder pembungkus sahaja).
4. Pastikan `index.html` berada terus di akar repositori, sebaris dengan `README.md`.
5. Pergi ke **Settings → Pages** dan pastikan sumber penerbitan menggunakan branch `main` dan folder `/(root)`.
6. Tunggu proses deployment selesai, kemudian buka: `https://syawalwahed-lgtm.github.io/PJ-6G-SELASA-8.00/`.

## Kandungan

- `index.html` — aplikasi interaktif PJ Tahun 6, termasuk nota, aktiviti pengukuhan, kuiz 25 soalan, laporan markah dan cetakan/PDF.
- `soalan_25_imbangan_cantik.json` — salinan bank soalan dalam format JSON.
